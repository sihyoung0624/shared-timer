# 공유 타이머 (같은 공간용 MVP)

같은 와이파이 안에서 여러 명이 각자 노트북·폰으로 **동일한 카운트다운을 실시간으로** 보는 타이머입니다.
발표·회의·수업·면접 등에서 진행자가 시간을 제어하고, 참석자는 큰 화면으로 남은 시간을 봅니다.

> 본 코드는 **기획자가 만든 프로토타입(MVP)** 입니다. 실서버 배포 전 아래
> "실서버 반영 전 체크리스트"를 반드시 검토해 주세요.

---

## 1. 빠른 실행 (Windows / 개발용)

```powershell
# 1) 가상환경 생성 (Python 3.11 권장)
py -3.11 -m venv .venv

# 2) 가상환경 활성화
.\.venv\Scripts\Activate.ps1

# 3) 패키지 설치
pip install -r requirements.txt

# 4) 실행
python app.py
```

실행하면 콘솔에 접속 주소가 표시됩니다.

- 이 컴퓨터:           `http://localhost:5050`
- 같은 와이파이 기기:  `http://<이PC의IP>:5050`  (콘솔에 자동 표시됨)

> **포트 안내:** 기본 포트는 **5050**입니다. (개발 PC에서 5000번을 다른 프로그램이
> 사용 중이라 5050으로 잡았습니다.) 변경하려면 환경변수 `PORT`를 쓰세요.
> 예) PowerShell: `$env:PORT=8000; python app.py`

---

## 2. 사용 방법

1. 홈(`/`)에서 시간을 설정하고 **타이머 만들기** 클릭
2. **두 개의 링크**가 발급됩니다.
   - **뷰어 링크** (`/v/<room_id>`) : 시간만 봄. 청중·발표 화면·프로젝터용
   - **컨트롤러 링크** (`/c/<room_id>/<token>`) : 시작·정지·리셋·시간조절. **진행자 본인만**
3. 진행자는 컨트롤러로 제어하고, 참석자에게는 **뷰어 링크만** 공유합니다.

## 4. 보안 설계 (의도)

이 프로토타입이 **의도적으로** 지킨 원칙입니다. 실서버에서도 유지해 주세요.

| 원칙 | 구현 위치 |
|------|-----------|
| 뷰어 / 컨트롤러 권한 분리 | 링크(URL) 자체를 분리. 뷰어는 토큰 없음 |
| 컨트롤러 토큰은 **서버에서 검증** | `_check_controller()` — 클라이언트가 보낸 토큰을 서버 보관값과 대조 |
| 외부로 나가는 데이터에 토큰 미포함 | `_snapshot()` 이 `control_token`을 항상 제외 |
| 동시 사용 시 데이터 보호 | `rooms_lock` (threading.Lock) 으로 방 데이터 보호 |
| 입력 검증 | 시간 범위(1초~24시간), 타입 체크, 접속 인원 상한(`MAX_VIEWERS`) |

## 5. ⚠️ 실서버 반영 전 체크리스트 (중요)

이 코드는 **사내 같은 와이파이용 MVP** 기준입니다. 외부 공개·운영 전 아래를 처리해야 합니다.

- [ ] **`SECRET_KEY` 환경변수 분리** — 현재 `app.py`에 실험용 고정값이 박혀 있음
      (`'dev-only-change-me-in-production'`). 운영용 랜덤 키를 환경변수로 주입할 것.
- [ ] **CORS 제한** — 현재 `cors_allowed_origins="*"` (전체 허용). 운영 도메인으로 좁힐 것.
- [ ] **운영용 WSGI 서버 사용** — 현재 Flask 내장 개발 서버(Werkzeug) 사용 중.
      운영 시 `gunicorn` + `eventlet`/`gevent` 등으로 교체 (동시 소켓 처리 성능·안정성).
- [ ] **방(room) 생성 남용·메모리 정리** — `/create`에 인증이 없어 누구나 방을 만들 수 있고,
      끝난 방이 메모리에 계속 남음. 운영 시 **생성 제한(rate limit) + 일정 시간 후 자동 정리(TTL)** 필요.
- [ ] **데이터 영속성 검토** — 현재 데이터는 **메모리에만** 저장(서버 재시작 시 전부 소멸).
      서버를 여러 대로 늘리면 방 데이터가 공유되지 않음 → 다중 서버 운영 시 Redis 등 외부 저장소 필요.
- [ ] **HTTPS 적용** — 토큰이 URL에 포함되므로, 외부 망에서는 반드시 HTTPS로.
- [ ] **방화벽** — 같은 와이파이 다른 기기 접속이 막히면 해당 포트 인바운드 허용 필요.

---

## 6. 알려진 제약 (MVP 범위)

- 진행자가 **컨트롤러 화면을 프로젝터에 직접 띄우면 주소창에 토큰이 노출**됩니다.
  → 발표·공유 화면은 반드시 **뷰어 링크**로 띄우세요. (그래서 링크를 분리해 둠)
- 접속 인원 상한은 `MAX_VIEWERS = 30` (코드 상단 상수). 필요 시 조정.
- 모든 기기는 **같은 네트워크**에 있어야 합니다. (외부 인터넷 공유 기능은 범위 밖)
